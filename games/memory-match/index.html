Memory Match

Flip two cards. If the pictures match, they stay open. Find all the pairs using as few moves as you can.

How to play

  1. Pick a levelStart with Easy (6 pairs). Stuck? Use Peek to look for a moment.
  2. Find its twinTap a second card. If the two pictures match, you got a pair!
  3. RememberIf they do not match, they flip back. Try to remember where each picture is.
  4. Clear the boardMatch every pair. Then try a harder level with more cards.

Did you know? Playing memory games makes you practise focus and recall. Try saying the pictures out loud in your head, like "cat is top left". That trick really helps!

Questions people ask

Is this memory game good for kids?

Yes. The pictures are simple and friendly, and Level 1 has only 6 pairs. Older players can try Level 4 with 12 pairs.

How do I get a better score?

Use fewer moves and less time. Try to remember where each picture was before you flip the next card.

Is it free?

Yes. There is no download and no sign-up.
