How to play

  1. Read the stonesEach row of numbers follows one rule.
  2. Find the ruleArithmetic adds the same number. Geometric multiplies by the same number.
  3. Beat the timerFast answers earn bonus points. Streaks build a combo up to ×3.
  4. Save the frogThree lives. A wrong answer is a splash. Reach the far bank to win.

Did you know? Money in a savings account that earns interest grows like a geometric sequence, while a weekly allowance that never changes grows like an arithmetic one.

Questions people ask

What is an arithmetic sequence?

A list of numbers where you add the same amount each time. For 3, 7, 11, 15 the common difference is 4. The nth term is an = a1 + (n − 1)d.

What is a geometric sequence?

A list where you multiply by the same number each time. For 2, 6, 18, 54 the common ratio is 3. The nth term is an = a1 × rn−1.

How can I tell them apart?

Subtract neighbouring terms. If the differences are all the same, it is arithmetic. If not, divide neighbouring terms. If the ratios are all the same, it is geometric.

Is this good for school and exam maths?

Yes. Sequences and series appear in IGCSE, GCSE, CBSE, IB, A-level and AP maths, and in problems on the SAT. The game builds the habit of finding the rule first.
